# public/video/

`hero-lembayung.mp4` belongs here, and nothing else does.

**R30 / R44: the hero video is MANDATORY and it is a hard deploy gate.** Veo Lite, 8 seconds,
16:9, 720p or better, muted autoplay loop. It is generated by Fahima Fauziah in Google Flow per
R63, from row **V01** of `MEDIA.md`, in the same single combined bundle as the logo pair and every
image.

Two things this directory must never contain:

- A `*.PLACEHOLDER.txt` or `VIDEO-PLACEHOLDER*.md` marker. That means the clip was never
  generated, and a build that ships with one is a FAILED build (R15).
- An mp4 under any other name. `src/components/Media.tsx` asks the build time filesystem manifest
  for exactly `video/hero-lembayung.mp4`; a wrong filename resolves to nothing and the hero falls
  back to the annotated placeholder, silently, on the live site.

Until the file lands, `<Media type="video">` renders the poster still or an honest annotated
placeholder. It NEVER points a `<video src>` at a file that is not on disk, which is how
dapur-tepat, portfolio-kilau, gunung-rezeki and sinyalkita all shipped frozen dead heroes.
